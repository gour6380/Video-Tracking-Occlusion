# Tracking results

There is no completed MOSEv2 experiment or official score in this repository. The [local test record](../verification/local-checks.json) and [synthetic tracking check](../verification/pre-upload-native-smoke.json) document implementation checks only.

After running the [notebook](../notebooks/video_tracking_occlusion.ipynb), open `runs/run_XXX/reports/technical-report.md` to see the metrics and examples from that run. This top-level directory is reserved for reviewed reports; raw videos, masks, checkpoints, and submission archives stay in the local run. See the [notebook guide](../docs/notebook-guide.md) for their locations.
